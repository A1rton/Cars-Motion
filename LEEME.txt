CarsMotion para Windows
=======================

1. En https://github.com/A1rton/cars-motion elegi Code - Download ZIP.
2. Abri el ZIP y entra en la carpeta del proyecto.
3. Hace doble clic en "Abrir CarsMotion.cmd". El sitio se abre en el navegador.
   Si Windows copia solo el CMD, el lanzador usa su propia copia del sitio.

Tambien podes usar Extraer todo y abrir el mismo CMD desde la carpeta extraida.
En ese caso, deja abierta la ventana del servidor mientras uses la pagina.
Si el navegador no se abre, copia la direccion local que muestra esa ventana.

Compatible con Windows 10/11 x64 y ARM64, y Windows 10 x86 con SSE2.
Windows 11 no tiene edicion de 32 bits. Usa un navegador moderno instalado, como Microsoft Edge.
El ZIP incluye el sitio y su servidor local. Funciona sin Internet, sin
instalar Node.js y sin permisos de administrador.

Los avisos de terceros estan en la carpeta licencias.
